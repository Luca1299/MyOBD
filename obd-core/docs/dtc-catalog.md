# Catalogo locale delle descrizioni DTC

DTC significa Diagnostic Trouble Code, codice diagnostico di guasto.
CC0 indica Creative Commons Zero; GM indica General Motors.
Il catalogo è un sottoinsieme deliberato di tre titoli generici di OBDex,
tradotti in italiano senza importare cause, costi, suggerimenti o codice
eseguibile della fonte. La ricerca è esatta: nessuna equivalenza fra un codice
del costruttore e un codice generico simile. Le altre voci hanno descrizione
non disponibile; questo non nasconde il codice letto.
